Hipcom Workspace

Para conectar ao banco de dados compartilhado da equipe, insira as credenciais do Supabase. Você só faz isso uma vez — ficará salvo no navegador.

Passo 1 — Supabase Project URL
Supabase → seu projeto → Settings → API → Project URL
Passo 2 — Supabase Anon Key
Supabase → Settings → API → anon public (não é a service_role key)

Não tem conta Supabase? Veja o guia PASSO-A-PASSO.md incluído no projeto.
